# All American Butcher Shop

Three design directions for the Weiser shop, sharing one content file.

**These previews are not for public release.** Unconfirmed copy, hours, phone, email, address details, services, and photos are wrapped in a yellow “Placeholder” marker. Every page also sends `noindex`.

## Run all three locally

```bash
npm install
npm run dev:heritage     # http://localhost:3000
npm run dev:storefront   # http://localhost:3001
npm run dev:editorial    # http://localhost:3002
```

Or start them together with `npm run dev` (three processes). The yellow preview bar at the top of each site jumps between versions on the same page path.

| Port | Version | Idea |
| --- | --- | --- |
| 3000 | Heritage Label | Printed butcher card: cream paper, rules, stars, lockup-first |
| 3001 | Bold Storefront | Shop-sign poster: navy blocks, oxblood type, numbered services |
| 3002 | Quiet Editorial | Magazine: photography, whitespace, quieter patriotic detail |

Confirmed from the logo / Facebook (not marked placeholder): business name, taglines, faith line, Weiser, Facebook URL.

Placeholder until the owners confirm: address, phone, email, hours, about story, owner names, services, policies, photos, map.
